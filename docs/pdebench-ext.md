# pde_benchmarks.tex Problems 12–16 (`--protocol pdebench-ext`)

Problems 12–16 of `pde_benchmarks.tex` (added 2026-10-23) under the same student protocol as `pdebench`. They need
periodic domains, a fourth-order term and vector fields. They therefore form their own suite, which leaves the
20-case `pdebench` suite, its splits and all earlier results unchanged.

| Problem | Case | Equation (library class) | Domain, conditions | Solution |
| --- | --- | --- | --- | --- |
| 12 Kuramoto–Sivashinsky | 12a manufactured | `u_t + u u_x + u_xx + u_xxxx = f` (`kuramoto_sivashinsky`) | (0, L) periodic | `A sin(2πx/L)(1 + t^β)` |
| | 12b chaotic | same, f = 0 | L = 32π, u₀ = cos(x/16)(1 + sin(x/16)) | ETDRK4 reference |
| 13 Navier–Stokes | 13a Taylor–Green | `u_t + (u·∇)u + ∇p − νΔu = 0`, `∇·u = 0` (`navier_stokes_2d`) | (0, 2π)² periodic, wavenumber k | closed form, F = e^(−2νk²t) |
| | 13b Kovasznay | same, steady | (−0.5, 1) × (−0.5, 1.5), Dirichlet velocity | closed form |
| 14 Cahn–Hilliard | 14a manufactured | `u_t = M Δ(u³ − u − ε²Δu) + f` (`cahn_hilliard_2d`) | (0, L)² periodic | `A cos kx cos ky (1 + t^β)` |
| | 14b spinodal decomposition | same, f = 0, M = 1 | (0, 2π)², small multi-mode u₀ | ETDRK4 reference |
| 15 Maxwell TE_z | 15a cavity mode | `E_t = c ∇×H − J`, `H_t = −c ∇×E` (`maxwell_te`) | (0, a) × (0, b), perfect conductor | TE_mn standing wave |
| | 15b current-driven | same, J ≠ 0 | same | manufactured |
| 16 Time-harmonic EM | 16a low frequency | `∇×∇×E − k²E = f` (`maxwell_time_harmonic`) | (0, 1)², perfect conductor | manufactured |
| | 16b high frequency | same, k between cavity eigenvalues | same | manufactured |

- **Splits:** training, validation and a sealed test split with one instance of each case (10 cases each).
  - Manufactured cases draw their numbers per split; literature cases use `pdebench_ext.FIXED`.
  - The 12b horizon is T = 30, 60 and 150. 14b uses ε = 0.15, 0.12 and 0.1, with its own initial modes per split.
- **Data:** 256 noisy samples of every component (1 % RMS noise per component) at random evaluation nodes.
- **Inputs:** black-box `forcing` (momentum forcing, current density J, or f), `initial`, and `boundary` (13b velocity).
- **Scoring:**
  - Linear interpolation onto the evaluation grid: 1-D 512 × 501; 2-D 129² × 21; steady 129².
  - Space-time and final-time relative L2 over all components together; pressure is compared without its mean.
  - Tolerance 2e-3; initial and boundary conditions to 1e-10. Boundary checks: periodic edges, the Dirichlet
    velocity (13b), and tangential E = 0 (15, 16).
  - 90 s for 1-D, 300 s for 2-D, 16 GB.
- **References for 12b and 14b:** Fourier spectral with ETDRK4, built by `scripts/build_pdebench_ext_references.py`
  into `data/pdebench_ext/references`. Each is checked against a half-resolution solve:

  | Reference | Coarse vs fine relative L2 | Margin to tolerance |
  | --- | --- | --- |
  | 12b | 1e-7 to 5e-7 | about 4,000× |
  | 14b | 7e-8 to 3e-5 | about 60× |

- **Code:**
  - `src/pde_rsi/equations_ext.py`: sandbox-visible inputs and closed forms.
  - `src/pde_rsi/pdebench_ext.py`: cases, evaluator and protocol.
  - `src/pde_rsi/pdebench_ext_reference.py`: reference solvers.
  - `tests/test_pdebench_ext.py`: every closed form satisfies its PDE; the evaluator accepts every exact and
    reference solution and rejects perturbed ones; real sandbox solves run on every layout.
- **Run:**

  ```bash
  bash scripts/run.sh code-agents --protocol pdebench-ext [--modular] --start scratch --model-config <cfg> --output runs/<name>
  ```

- **Release:** the training and validation cases are on Hugging Face under `pdebench_ext/` (2026-10-23); the sealed
  split is withheld. All benchmarks are described in `docs/pde-rsi-benchmarks.tex`, generated by
  `scripts/write_benchmarks_latex.py`.
